# 🎮 Jeu de Détonateur - Module Braille

Un jeu passionnant où vous devez décoder des messages en Braille pour désamorcer un détonateur!

## 🚀 Installation

1. Téléchargez tous les fichiers dans un dossier
2. Ouvrez le dossier dans VS Code
3. Exécutez `main.py`

## 🎯 Comment jouer

- **Mode Complet**: Module Braille avancé avec 3 essais
- **Mode Rapide**: Défi express avec 2 essais
- **Mode Entraînement**: Pratique sans limite d'essais

## 🎓 Apprentissage du Braille

Le jeu inclut un système d'aide pour apprendre le code Braille basique.

## 📁 Fichiers

- `main.py`: Programme principal
- `module_braille.py`: Module de jeu Braille
- `game_manager.py`: Gestionnaire de statistiques
